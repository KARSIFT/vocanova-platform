# Security

Report suspected vulnerabilities or other security concerns privately to the KARSIFT repository maintainers. Do not disclose security concerns in public issues, discussions, pull requests, or commits. Maintainers will coordinate a secure reporting channel and next steps.

Secrets, credentials, access tokens, private keys, and production configuration must never be committed to this repository. If sensitive information is exposed, notify the maintainers privately so it can be revoked and remediated.

AI agents must never receive production secrets or access to production credentials.
