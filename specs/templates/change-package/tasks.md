# VOC-000 — Tasks

## VOC-000-T00 — REPLACE WITH APPROVED TASK

- Requirement source: `VOC-000-D00`
- Acceptance criteria: `VOC-000-AC-00`
- Tests: `VOC-000-TEST-00`
- Evidence: `VOC-000-EV-00`
- Implementation pull-request mapping: same implementation PR unless the package
  explicitly records more than one
- Status: pending

Tasks must preserve scope, separation of duties, and rollback safety. One
minimum-sufficient task is valid when it preserves clear mapping. Task IDs group
requirements, dependencies, tests, and evidence; they do not imply separate branches
or pull requests.
