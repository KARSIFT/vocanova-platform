05 · live boundary

Ready is not activated

Repository implementation can close while all live actions remain held. A future activation package must name the exact action, accountable role, required evidence, and completion or expiry condition. Risk class alone neither grants authority nor creates a founder-approval requirement.

06 · rollback + next state

Repository rollback is exact

Reverse-order rehearsal operates only in a disposable worktree. Every task boundary must reproduce its predecessor's tree byte-for-byte. This proves repository reversibility; it does not inspect or recover an unqueried live system, and D1 recovery remains forward-corrective.
